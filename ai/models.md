# Snapdragon AI model path

## Vision-language
Qwen3-VL-4B-Instruct is the proposed vision-language model for hairstyle-reference understanding and structured preference extraction.

## Speech
Distil-Whisper is the proposed speech-to-text model for converting spoken style preferences into text.

## Runtime
The production Snapdragon path should use a Qualcomm-supported Windows/Snapdragon runtime and be validated on the actual target HP Snapdragon PC.

**Important:** this repository's default demo engine does not claim NPU execution. Record real latency, memory and execution-provider measurements only after testing the integrated build on target hardware.
