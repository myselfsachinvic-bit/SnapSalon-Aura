\# SnapSalon Aura



\### SEE IT. SAY IT. SAVE IT. BOOK IT.



SnapSalon Aura is a privacy-first AI Style Passport designed for Snapdragon-powered HP PCs.



It combines:

\- Hairstyle reference image understanding

\- Natural voice/text preferences

\- On-device AI inference

\- Structured Barber Brief generation

\- Personal Style Passport

\- Salon-ready communication



\## Core Concept



Image + Voice

↓

Local AI

↓

Barber Brief

↓

Style Passport

↓

Salon Action



\## Snapdragon AI



The project is designed to use Qualcomm AI Hub models for:

\- Vision-language understanding

\- Speech-to-text



The final implementation will be optimized and benchmarked on a Snapdragon-powered HP PC.



\## Planned Stack



\- React + Vite

\- Qualcomm AI Hub

\- Snapdragon NPU

\- Python/local AI service

\- Java/Spring Boot for optional application services

\- Local structured storage



\## Privacy



Personal image and voice inputs are intended to remain on-device during AI inference.



The project does not perform:

\- Identity recognition

\- Medical/dermatological analysis

\- Personality inference

\- Guaranteed appearance prediction
